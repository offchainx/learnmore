# Story-045p: 定价体系重构与转化策略设计

**状态**: Draft
**日期**: 2026-02-03
**目标**: 重构定价与权益体系，建立以“效率”为核心的付费墙，驱动用户从“免费/自学版”向“智学版 (Tier 3)”转化。

---

## 1. 核心战略逻辑

本次重构不再单纯堆砌功能数量，而是通过 **“效率差”** 和 **“数据价值”** 来区分层级。

### 1.1 核心价值主张：买资源 vs 买时间
*   **Tier 2 (自学版)**：卖的是**“资源”**。题多、卷子全，但需要用户自己筛选、自己查找解析。这制造了“费力”的痛点。
*   **Tier 3 (智学版)**：卖的是**“捷径”与“时间”**。AI 告诉用户学什么、只做该做的题。通过消除 Tier 2 的痛点来驱动升级。

### 1.2 软性限制策略：数据回溯期 (Data Retention)
参考 AI Coding 工具的模式，不强制切断功能，而是限制“记忆”。
*   **逻辑**：只有保留足够久的数据，AI 的个性化算法才能生效（如遗忘曲线）。
*   **设定**：
    *   **体验版**：仅保留最近 **7天** 数据。用户的“数字分身”永远长不大，长期价值被锁死。
    *   **自学版**：保留 **30天** 数据。
    *   **智学版+**：**永久保存**。

### 1.3 体验版定位：众包训练师 (Crowdsourcing)
*   **目的**：最大化体验版用户基数，不设硬性使用时长限制。
*   **价值交换**：体验版用户在做题、查看基础答案时的行为数据（点击、停留时长、正确率），用于反哺题库的难度打标和质量清洗。
*   **产品化方向**：不仅后台静默收集，而是让用户**看到自己的贡献**。做题后显示 `"你的答题数据已帮助 X 名学生标定难度"` — 建立"贡献身份认同"，降低离开成本。长期可延伸为轻量的 "贡献积分" 体系（累计量换取一次性功能解锁），但不影响核心付费漏斗。

### 1.4 试用期策略
*   仅 **自学版 (Standard)** 开放 **7 天免费试用**。按钮文案直接标注 `免费试用 7 天`，不藏在流程里。
*   智学版和领航版暂不开放试用 — 核心 AI 功能尚在迭代，待功能稳定后再开放，避免体验期望差。
*   试用期结束后降级至体验版。试用期内数据按自学版规则保留（30 天回溯期），到期后按体验版规则滚动清除。

## 3. 权益矩阵详解 (Feature Matrix)

我们将权益切分为四个核心维度，每一刀都旨在精准区分用户需求。

### A. 内容深度 (Content Depth)
*剔除“视频画质”等伪需求，聚焦“解题深度”与“实战仿真”。*

*   **体验版**: 
    *   **题库**: 基础练习 (Basic Drills) - 课本难度。
    *   **解析**: **仅参考答案 (Answer Key Only)** - 只知对错，不知过程。
*   **自学版**: 
    *   **题库**: 历年真题 (Past Year Papers) - 实战题海。
    *   **解析**: **详细文字解析 (Step-by-step)** - 需耐心阅读文字步骤。
*   **智学版**: 
    *   **题库**: 专项强化训练 (Topic-Specific Training) - 针对薄弱点推送。
*   **领航版**: 
    *   **题库**: 高阶挑战包/考前押题 (Challenge Packs) - 稀缺资源。
    *   **解析**: 优先获取新题解析。

### B. AI 效率与算法 (AI Efficiency)
*去人格化，重算法调度。砍掉不可控的 AI 闲聊。*

*   **体验版**: 
    *   **记忆容量**: **7天** (滚动覆盖)。
    *   **算法**: 无，随机做题。
*   **自学版**:
    *   **记忆容量**: **30天**。
    *   **算法**: 自动错题收录 (仅收集，无智能复习计划)。
    *   ⚡ **Preview Hook**: 每做错 5 题触发一次 — 答案下方闪一条半透明提示：`"AI 可以分析你做错的原因 ——— [升级查看]"`。让用户感知智学版的存在，比单纯撞墙式 FeatureLock 更自然。同理，复习页面可闪示模糊的 `📅 今天有 3 题待复习` 日程卡，内容模糊但天数可见。
*   **智学版**:
    *   **记忆容量**: **无限 (Unlimited)**。
    *   **算法**: **艾宾浩斯遗忘曲线** (自动安排复习) + **归因诊断** (分析为何做错)。
*   **领航版**: 
    *   **记忆容量**: 无限。
    *   **算法**: 智能弱项击破 (AI 针对弱项生成高强度训练)。

### C. 社区氛围 (Community)
*分层运营，保证高付费用户的专注环境。*

*   **体验版**: **仅浏览 (Read-only)**。只能看精华帖，不可发言（防止水军/低质内容）。
*   **自学版**: **互助论坛 (Discussion Forum)**。文字发帖，同伴互助。
    *   ⚡ **社交证明**: 学习页面放置实时状态窗口 `📚 现在有 X 人正在一起学习`，但点击后引导至智学版升级页。利用社交压力 + FOMO 驱动转化，且后续自习室人数越多，这个钩子越有力。
*   **智学版**: **虚拟自习室 (Virtual Study Room)**。沉浸式、静音、专注时长排名的"陪伴感"空间。
*   **领航版**: **精英俱乐部 (Elite Circle)**。高分圈层，可能有官方运营介入。

### D. 家长与支持 (Parent & Control)
*从“知情”升级为“对齐目标”。*

*   **体验版**: 无。
*   **自学版**: **月度简报 (Monthly Email)**。低频触达。
*   **智学版**: **实时 App 访问 + 周报**。家长可随时查看进度，心中有数。
*   **领航版**: **共同目标设定 (Joint Goal Setting)**。家长在 App 设定目标（如每周刷 5 小时），系统辅助监督，达成有反馈。

### E. 数据与导出 (Data & Export)
*数据沉淀作为留存机制，导出功能作为权益差异。用户攒的数据越多越不愿意离开。*

*   **体验版**: 无数据导出功能。学习记录仅保留最近 7 天，滚动清除。
*   **自学版**: 可导出**最近 30 天**的学习报告 (PDF)。仅限已保留时间范围内的数据。
*   **智学版**: 可导出**全部历史**学习报告 + 错题集 (PDF)。数据永久保存，导出无次数限制。
*   **领航版**: 同智学版。附加：家长可从独立入口下载子账户学习报告，方便家长与学校沟通。

## 4. 废弃与调整项 (Change Log)

1.  **移除**: 视频画质区分 (SD/HD/4K) - 对教育产品非核心痛点。
2.  **移除**: AI 导师对话次数 (5次/20次/100次) - 聊天机器人结果不可控，且容易分散注意力，改为后台算法驱动。
3.  **移除**: 作文批改 - 暂时移除，聚焦理科/客观题算法。
4.  **移除**: 纸质作业打印 - 流程太重，领航版改为更轻量的目标管理。
5.  **调整**: "终极版"更名为"领航版"，去除单纯的"土豪"感，强调引导与规划。

## 5. UI/UX 呈现建议

### 5.1 定价页 (Pricing Page) 文案策略

**核心逻辑**: 先让用户被智学版吸引，再在比较表里发现体验版的限制 — 产生 "原来如此" 的感知，而不是一开头就看到限制被劝退。

*   **数据回溯期的呈现**:
    *   **Card 层面**: Starter card **不显式提** "7天限制"。Smart Plus card 的 features 里正面写：`"AI 学习记忆无限，效果持续累积"`。
    *   **比较表层面**: AI 类别下加 `学习记忆时长` 行。值为 `7天(滚动) / 30天 / 无限 / 无限`。Starter 的 "7天(滚动)" 旁加小注 `较旧记录会自动清除`；Smart Plus 的 "无限" 旁加绿色标签 `AI效果最佳`。
    *   **类别引导文**: 比较表 AI 类别标题下加：`AI 的个性化精度取决于学习记忆时长`。
*   **Starter "社区验证" 感知**: Card 中强调 `Community Verified`，暗示用户在参与共建。配合做题后的 "帮助了 X 名学生" 提示，形成贡献身份认同。
*   **Standard 试用期标注**: 按钮文案为 `免费试用 7 天`，直接在 card 上标注。
*   **高亮推荐**: 保持 **智学版 (Smart Plus)** 为 "Best Value / 最受欢迎"。

### 5.2 产品内转化触发 (In-App Conversion Hooks)

这些机制配合使用，形成一个从"感知差距"到"看到影子"再到"升级"的漏斗，而非单点撞墙。

| 机制 | 触发条件 | 展现形式 | 针对层级 |
|------|----------|----------|----------|
| **Preview Hook** | 自学版用户每做错 5 题 | 答案下闪一条：`AI 可以分析你做错的原因 [升级查看]` | Standard → Smart Plus |
| **效率对比 (Efficiency Mirror)** | 在同一题目停留 > 3 分钟 | 显示：`智学版用户解决此类题目平均仅需 X 分钟` | Standard → Smart Plus |
| **社交证明 (Social Proof)** | 自学版学习页加载时 | 实时状态：`📚 现在有 X 人正在一起学习`，点击引导升级 | Standard → Smart Plus |
| **记忆衰减可视化 (Memory Decay)** | 体验版学习页每日刷新 | 衰减进度条：`你的学习记录将在 X 天后开始丢失 ████░░` | Starter → Standard |
| **众包贡献感 (Crowdsourcing ID)** | 体验版做题后 | `你的答题数据已帮助 X 名学生` — 不驱动升级，驱动活跃留存 | Starter 留存 |
