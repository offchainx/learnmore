# 背景
- community 兼顾内容流和互动，需要和主产品语言一致，但不能抢走学习产品主路径的注意力。

# 目标（Goals）
- 重构社区列表、详情和发帖体验
- 保留互动功能与内容浏览主链路
- 使社区风格与整体产品统一

# 非目标（Non-Goals）
- 不新增社区玩法
- 不改社区后端数据模型

# 稳定边界
- 社区是辅助学习场景，不应比主训练流更强势
- 必须保留阅读、发帖、互动的主链路
