# 背景
- marketing 域承担品牌气质、信任感和用户首次认知，是 UI 重构的外部表达核心。

# 目标（Goals）
- 重做 marketing 域视觉与信息层级
- 保留既有营销主路径与转化入口
- 去掉明显 AI SaaS 模板感

# 非目标（Non-Goals）
- 不修改支付或注册主流程契约
- 不在本阶段做内部产品页改造

# 稳定边界
- 营销页必须体现“温暖教育 + 编辑感产品”
- 不允许因为审美重构删除营销主入口或关键信息
