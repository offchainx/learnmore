# T-004 全站统一开发基线

## 文档定位
- 目的：为 `T-005 ~ T-019` 提供统一字段口径、命名规范、状态定义、数据源优先级、核账规则与页面任务模板。
- 适用范围：所有正式页面、正式接口、正式写操作；不适用于纯视觉装饰模块或实验性调试页。
- 生效原则：后续页面任务不得绕过本基线重新定义字段含义或统计口径；确需例外时，必须在对应页面任务中显式记录“偏离原因 + 替代规则”。

## 统一原则
1. 单字段单口径：同一业务字段在全站只能有一种定义。
2. 原始值优先：服务端返回原始可核账值，展示格式化放在 UI 层完成。
3. 真数据优先：页面字段必须来自真实数据库、真实上游服务或可复算聚合；禁止 mock 兜底。
4. 空态优先于假态：后端未完成、无数据或无权限时，显示空态、禁用态或明确错误，不允许假成功。
5. 写操作必须可回放：所有创建、提交、领取、支付、评论、保存操作都要可核账、可重试、可识别重复提交。
6. 页面与数据库双向可追踪：页面字段能追到表，表变化能追到页面动作。

## T-004.1 统一字段字典

### 通用字段定义
| 字段 | 类型 | 统一定义 | 存储/返回要求 | UI 规则 |
|---|---|---|---|---|
| `score` | `number` | 单次练习/考试得分百分比 | 整数 `0-100` | UI 显示 `85%` |
| `accuracy` | `number` | 正确数 / 总作答数 * 100 | 整数 `0-100` | 不返回字符串百分号 |
| `progress` | `number` | 当前对象完成进度百分比 | 整数 `0-100` | UI 负责进度条映射 |
| `masteryLevel` | `number` | 掌握度百分比 | 整数 `0-100` | 若有等级文案，由 UI 二次映射 |
| `studyTimeSeconds` | `number` | 学习时长原始秒数 | 服务端返回秒数 | UI 再格式化为 `xh ym` |
| `durationSeconds` | `number` | 单次会话/动作耗时秒数 | 服务端返回秒数 | 不在服务端拼接“分钟” |
| `questionsCount` | `number` | 题目数量或作答数量 | 非负整数 | 命名显式带 `Count` |
| `mistakesCount` | `number` | 错误作答次数 | 非负整数 | 若是“去重错题数”必须另起字段名 |
| `streakDays` | `number` | 连续有效学习日天数 | 非负整数 | 不复用为登录天数 |
| `xp` | `number` | 当前经验值总量 | 非负整数 | 等级由规则映射，不在 UI 写死 |
| `level` | `number` | 基于 XP 规则计算出的当前等级 | 正整数 | 计算规则必须统一 |
| `rank` | `number \| null` | 榜单 1-based 排名 | 正整数或 `null` | `null` 表示未上榜 |
| `activeDays` | `number` | 窗口内有“有效学习事件”的自然日数量 | 非负整数 | 不混用登录日与学习日 |
| `createdAt` / `updatedAt` | `ISO string` 或 `Date` | 数据创建/更新时间 | 接口层统一一种序列化方式 | 相对时间展示由 UI 处理 |

### 语义冲突字段禁止项
- 禁止把 `mistakesCount` 当成“去重错题本数量”。
- 禁止把 `score` 和 `accuracy` 混用。
- 禁止把 `progress` 当作“掌握度”。
- 禁止在服务端返回 `studyTime: "1.5h"` 这类展示字符串；应返回原始数值字段，再由 UI 格式化。

### 页面聚合字段命名规范
| 场景 | 正确命名 | 禁止命名 |
|---|---|---|
| 总览汇总 | `dashboardStats`, `overviewStats`, `practiceSummary` | `data`, `info`, `resultData` |
| 列表分解 | `subjectBreakdown`, `recentPracticeItems` | `listData`, `itemsData` |
| 趋势数据 | `dailyActivitySeries`, `scoreTrendSeries` | `chartData` |
| 空态计数 | `totalCount`, `completedCount`, `pendingCount` | `count1`, `count2` |

## T-004.2 统一时间窗口定义
| 概念 | 统一定义 |
|---|---|
| 今日 | 按用户时区自然日；无用户时区配置时按应用默认时区 `Asia/Kuala_Lumpur` |
| `7D` | 包含今天在内的最近 7 个自然日 |
| `30D` | 包含今天在内的最近 30 个自然日 |
| 最近记录 | 默认取最近 3 条；若页面另有规定，必须在页面任务中明确写出 |
| 活跃日 | 当天存在“有效学习事件”才算活跃，不以单纯访问页面为准 |
| 有效学习事件 | 至少包括：完成练习提交、完成考试提交、完成课程/lesson、完成任务推进；是否包含登录必须显式定义 |

## T-004.3 统一数据源优先级
1. 权威写表 / 权威上游服务  
   例：`users`、`exam_records`、`user_attempts`、Stripe webhook 状态。
2. 可复算聚合  
   例：按 `user_attempts` 聚合 `accuracy`、按 `exam_records` 聚合 `studyTimeSeconds`。
3. 物化缓存 / 冗余字段  
   仅当可由权威源复算，且写入逻辑已定义幂等策略时可使用。
4. UI 空态 / 禁用态  
   仅用于无数据、无权限、未开通能力场景。

### 强制规则
- 页面一个字段只能有一个权威来源。
- 若字段来自冗余列，必须在页面任务中写明回填逻辑与复算 SQL。
- 禁止使用 mock、硬编码演示值、随机值作为正式页面展示来源。

## T-004.4 统一命名规范

### 路由与页面
- 路由目录：`kebab-case`
- 页面任务标题：`页面族 + 目标动作`
- 页面组件：`PascalCase`
- 页面 client wrapper：`XxxClientWrapper`

### Server Action / API
| 动作类型 | 前缀 |
|---|---|
| 读取单个对象 | `get` |
| 读取列表 | `list` |
| 创建 | `create` |
| 更新 | `update` |
| 删除 | `delete` |
| 提交/完成 | `submit`, `complete`, `claim` |
| 校验/刷新 | `check`, `ensure`, `refresh`, `sync` |

### 字段命名
- 布尔值：`is*`, `has*`, `can*`
- 数量：`*Count`
- 百分比：`*Rate`, `*Percent`, `accuracy`, `progress`, `masteryLevel`
- 秒数：`*Seconds`
- 时间点：`*At`
- 展示字段：如必须存在，后缀 `Label`, `DisplayText`

## T-004.5 统一状态机定义

### 页面数据状态
| 状态 | 含义 | UI 要求 |
|---|---|---|
| `loading` | 正在读取 | skeleton / loading 状态 |
| `ready` | 成功返回且有可展示数据 | 展示正式内容 |
| `empty` | 请求成功但无数据 | 展示空态，不造数据 |
| `forbidden` | 无权限 | 展示权限提示或跳转 |
| `error` | 请求失败 | 展示错误提示，可重试 |
| `disabled` | 功能下线或未开放 | 展示禁用态，不伪装可用 |

### 写操作状态
| 状态 | 含义 |
|---|---|
| `idle` | 未触发 |
| `submitting` | 已发起请求，等待结果 |
| `success` | 成功且已落库/已同步 |
| `failed` | 失败且无副作用或副作用已可识别 |
| `duplicate` | 重复提交已识别并安全返回 |

### 任务/奖励状态统一语义
| 状态 | 定义 |
|---|---|
| `IN_PROGRESS` | 未达成，仍可推进 |
| `COMPLETED` | 已达成，待领取/待确认 |
| `CLAIMED` | 奖励已领取，不可重复领取 |

## T-004.6 统一核账规则

### 字段级核账要求
每个页面任务至少交付以下矩阵：
| 页面字段 | 页面组件 | Action/API | 数据表/服务 | 计算公式/过滤条件 | 核账方式 |
|---|---|---|---|---|---|
| 示例：`accuracy` | Dashboard 顶部卡片 | `getDashboardStats` | `user_attempts` | `correct / total * 100` | SQL + 页面截图 |

### 写操作核账要求
每个关键写操作至少保留：
1. 触发前页面状态
2. 请求输入摘要
3. 数据库/上游执行前快照
4. 数据库/上游执行后快照
5. 页面成功/失败反馈截图
6. 重复提交再次执行结果

### 幂等规则
- `ensure*`、`sync*`、webhook、奖励领取、任务创建必须天然幂等。
- 同一用户、同一业务键、同一自然日或同一外部事件 ID，重复执行不得产生重复脏数据。
- 若无法天然幂等，必须定义唯一键、去重键或状态锁。

## T-004.7 统一页面任务模板

### 所有页面族任务固定拆法
| 后缀 | 必做内容 | 产出 |
|---|---|---|
| `.1` | 盘点路由、页面、组件、CTA、当前数据源 | 页面清单 |
| `.2` | 建立字段映射与权威数据源矩阵 | 字段映射表 |
| `.3` | 读接口 / 聚合逻辑对齐 | Action/API 改造清单 |
| `.4` | 写接口 / 权限 / 幂等对齐 | 写操作清单 |
| `.5` | 清理 mock / fallback / 假成功，补空态、错误态、禁用态 | UI 规则清单 |
| `.6` | 本页面族验证：冒烟、字段核账、重复提交/刷新验证 | 验收证据 |

### 页面任务完成定义
- 已完成字段字典与来源映射
- 已完成 mock 清理或禁用态处理
- 已完成关键写操作核账
- 已完成本地验证
- 已纳入预发复测清单
