# 验收标准（Acceptance）

## 功能验收
1. 给定：存在有效推荐关系（`referrals.status = PENDING`）  
   当：被推荐人完成首付并触发 webhook  
   则：推荐关系正确结算（`COMPLETED`），且奖励字段与订阅字段正确更新。  
2. 给定：触发通知的业务事件（如支付成功）  
   当：通知链路执行  
   则：通知可写入 `notifications`，并在客户端可读取与更新状态。  

## 测试清单
- [ ] referral 主流程通过（注册绑定 -> 首付 -> 奖励发放）
- [ ] referral 幂等重放通过（同 event 不重复发放奖励）
- [ ] notification 创建通过（至少 BILLING 一条）
- [ ] notification 状态流转通过（未读 -> 已读）
- [ ] 核对证据已附（SQL / 日志 / 截图）

## 边界与失败场景
- 场景：webhook 重放或并发触发。  
  - 期望行为：不重复发奖励，不产生重复处理记录。  
- 场景：通知写入失败。  
  - 期望行为：返回可识别错误并可定位日志。  

## 发布检查
- [ ] 文档已更新
- [ ] 风险已评估
- [ ] 回滚方案可执行
- [ ] referral 与 notification 两项均通过
