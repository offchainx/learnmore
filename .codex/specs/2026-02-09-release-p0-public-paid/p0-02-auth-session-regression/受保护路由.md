# 受保护路由基线清单（T-006 单一事实源）

## 规则说明
- 受保护路由组：`/admin/**`、`/dashboard/**`
- 未登录访问受保护路由：必须重定向到 `/login?redirectTo=原始路径`
- 已登录访问 `/login`、`/register`：按 `redirectTo` 或默认 `/dashboard` 跳转
- `/admin`：已登录且具备权限时，应进入管理员总览面板（不再重定向到 `/admin/content/review`）
