# 验收标准（Acceptance）

## 总体验收
1. 所有 p0-xx 文档具备可执行性，不再是空模板。
2. 每个任务 acceptance.md 都包含并填写：
   - Server Action 验证矩阵
   - 数据表核对矩阵（含 SQL 前后快照）
3. 所有关键场景均完成 本地 + 预发 双环境验证。
4. 未经用户批准，不进入代码实现。

## P0 必过场景
- [ ] 数据库：schema/字段逻辑映射完整，冗余项清理可回滚
- [ ] 认证：登录、登出、超时、跨标签、受保护路由
- [ ] Practice：拉题、提交、判分、错题回写、配额
- [ ] Leaderboard：周期切换、我的排名、空榜处理
- [ ] Community：发帖、评论、点赞、详情页流转
- [ ] Achievement：触发授予、防重复、展示正确
- [ ] Billing：下单成功、取消返回、Webhook 重放幂等
- [ ] 发布：生产 env 校验、冒烟、回滚演练

## 发布门禁
- [ ] 每个子任务已完成文档审阅并得到用户确认
- [ ] 每个子任务已提供 Action 与 SQL 证据
- [ ] 风险与回滚策略可执行
