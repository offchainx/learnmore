# 验收标准（Acceptance）

## 功能验收（Given / When / Then）
- 给定：P0 关键模块已具备文档与实现
  当：执行本地与预发冒烟
  则：关键路径均可追踪、可回滚。
- 给定：发生失败场景
  当：查看日志与数据快照
  则：可在单轮排查中定位到具体 action 与数据表。

## Server Action 验证矩阵（本地 + 预发都要执行）
| Action 名称 | 调用入口（页面/按钮/事件） | 输入样例（正常/异常） | 权限校验（未登录/越权） | 预期输出（成功/失败） | 幂等要求 | 日志与错误码 | 结果（pass/fail） | 证据 |
|---|---|---|---|---|---|---|---|---|
| 核心读接口集合 | Dashboard、Leaderboard、Community 页面 | 正常：基础访问；异常：越权访问 | 越权应拒绝或降级 | 页面可用且日志可定位 | 查询幂等 | 访问日志含 path 与 latency |  |  |
| submitQuiz | Practice 提交 | 正常：完整答案；异常：非法题目 | 未登录拒绝 | 成功返回结果；失败有错误码 | 重放行为可解释 | quiz 错误日志 |  |  |
| POST /api/webhook/stripe | Stripe 事件 | 正常与重放 | 验签必须通过 | 更新一次且可审计 | eventId 幂等 | webhook 处理日志 |  |  |

## 数据表核对矩阵（逐项）
| 场景 | 相关表 | 关键字段 | 执行前快照（SQL + 摘要） | 执行后快照（SQL + 摘要） | 差异判断 | 回滚验证 | 结果/证据 |
|---|---|---|---|---|---|---|---|
| 练习冒烟核账 | exam_records, user_attempts, error_book | 主键与关联键 | 执行前查询最近记录 | 执行后再次查询 | 新增记录关联正确 | 回滚后再次冒烟 |  |
| 支付冒烟核账 | users, notifications | 订阅字段与事件链接 | 支付前查询订阅状态 | webhook 后再次查询 | 订阅变化加 event 记录齐全 | 重放事件不重复写入 |  |
| 排行榜冒烟核账 | leaderboard_entries | period、score | 提交前查询 score | 提交后查询 score | 分数变化符合预期 | 回滚后复核 |  |

## 发布检查
- [ ] 本地验证完成并附证据
- [ ] 预发复测完成并附证据
- [ ] 幂等与越权场景通过
- [ ] 回滚方案可执行
- [ ] 已获得用户批准进入开发
