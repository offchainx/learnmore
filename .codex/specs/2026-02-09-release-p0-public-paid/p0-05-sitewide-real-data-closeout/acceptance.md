# 验收标准（Acceptance）

## 功能验收（Given / When / Then）
- 给定：后续任一页面任务开始实施
  当：开发人员定义字段、状态、命名、核账方式
  则：必须遵循 `sitewide-real-data-governance-template.md`，不得自行重新定义口径。
- 给定：用户访问任一正式页面
  当：页面完成加载
  则：页面展示数据必须来自真实接口/真实数据库/真实上游服务，不允许展示 mock 业务数据。
- 给定：用户执行任一核心操作（如开始练习、提交答案、发表评论、保存设置、发起支付）
  当：操作成功
  则：页面反馈、接口返回与数据库状态必须一致，可追踪、可核账。
- 给定：后端能力未完成或无数据
  当：用户进入对应页面或点击对应功能
  则：页面必须展示明确空态、禁用态或错误提示，不允许假成功、假榜单、假题目、假记录。
- 给定：用户重复刷新页面或重复提交同一动作
  当：同一请求被重复触发
  则：系统不得产生异常重复写入、重复发奖、重复扣费、重复记录。
